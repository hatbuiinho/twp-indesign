# Layout

Đặt PDF nguồn và INDD hoặc IDML nguồn trong thư mục này. Mỗi trang PDF của
Tập 53 tương ứng với một spread. Đặt tên file không dấu, ví dụ
`t53-part-2.pdf`. Dùng phần tên bỏ đuôi làm `<layout-slug>`.

Lưu tất cả bản dàn theo spread, ảnh liên kết, outline, PDF xem trước và
tệp bàn giao trong `outputs/<layout-slug>/<spread>/`. Git bỏ qua `outputs/`.
